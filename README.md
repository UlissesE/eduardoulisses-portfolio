# 👋 Olá, bem-vindo ao meu Portfólio!

Este repositório contém o código-fonte do meu site pessoal. É aqui que apresento meus projetos, minhas habilidades e um pouco sobre mim. O objetivo deste projeto não é apenas mostrar meu trabalho, mas também demonstrar minha evolução como estudante de Engenharia de Software e desenvolvedor Fullstack.

O design foi pensado para ser moderno, interativo e performático, utilizando o que há de mais recente no ecossistema React.

## ✨ Funcionalidades do Projeto

* **Design Responsivo:** Layout adaptável para mobile, tablet e desktop usando TailwindCSS.
* **Animações Fluidas:** Animações de página e micro-interações suaves com Framer Motion.
* **Background Interativo:** Uso de componentes criativos (ReactBits) para dar vida ao fundo da página e a alguns elementos.
* **Integração com API:** Consumo de arquivo Json para listar meus projetos automaticamente.
