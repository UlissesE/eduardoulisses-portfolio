// 01 · CONTEXTO

Fundamentos antes do framework

Frameworks como o Spring Boot resolvem muita coisa automaticamente: injeção de dependência, persistência, tratamento de erros. Antes de delegar isso, quis provar que conseguia construir cada peça à mão.

O resultado é um sistema de cadastro de clientes com dois tipos — Pessoa Física (CPF) e Pessoa Jurídica (CNPJ) — com CRUD completo, validações e persistência entre execuções, usando só a biblioteca padrão do Java.

// 03 · DECISÕES

Decisões e desafios

DECISÃO

Sem framework

Cada responsabilidade que o Spring automatiza foi escrita à mão, para entender o que acontece por baixo.

DECISÃO

Exceções customizadas

Cada regra de negócio violada tem sua própria exceção, em vez de erros genéricos.

DECISÃO

Soft delete

Clientes removidos são marcados, não apagados. [Por quê? Histórico, auditoria, reativação?]
